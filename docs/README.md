## 🌟 **Project Highlights**

### **✨ Key Features**
- **Multi-tenant Architecture** - Support for multiple companies
- **Role-based Access Control** - Granular permissions system
- **Comprehensive CRM** - Client, project, and task management
- **Real-time Updates** - Live project tracking and notifications
- **Advanced Security** - JWT authentication with token blacklisting
- **Scalable Design** - Built for enterprise-level usage

### **🛠️ Technology Stack**
- **Backend**: Node.js + Express.js
- **Database**: MongoDB + Mongoose
- **Authentication**: JWT + bcrypt
- **Security**: Helmet, CORS, Rate Limiting
- **Validation**: Express-validator
- **Documentation**: OpenAPI/Swagger

### **📊 System Capabilities**
- **User Management**: Admin, Employee, and Client accounts
- **Project Management**: Digital marketing and development projects
- **Task Management**: Assignment, tracking, and time management
- **Client Management**: Relationship and communication tracking
- **Reporting**: Analytics and performance metrics
- **Communication**: Internal and external messaging

## 🚀 **Quick Start**

### **1. Clone Repository**
```bash
git clone <repository-url>
cd CRIPCOCODE_CRM_PROJECT
```

### **2. Install Dependencies**
```bash
npm install
```

### **3. Configure Environment**
```bash
cp env.js.example env.js
# Edit env.js with your configuration
```

### **4. Start Development Server**
```bash
npm run dev
```

### **5. Access Application**
- **API**: http://localhost:5000/api
- **Health Check**: http://localhost:5000/health
- **Documentation**: http://localhost:5000/docs

## 📋 **System Requirements**

### **Minimum Requirements**
- **Node.js**: v16.0.0 or higher
- **MongoDB**: v4.4 or higher
- **RAM**: 2GB minimum
- **Storage**: 10GB available space

### **Recommended Requirements**
- **Node.js**: v18.0.0 or higher
- **MongoDB**: v6.0 or higher
- **RAM**: 4GB or higher
- **Storage**: 20GB available space
- **CPU**: 2 cores or higher
